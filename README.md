# Car Market Trends Analysis Using CarDekho Data

## Project Overview

Car Market Trends Analysis is a data analysis project developed using Python to explore and understand used-car market data from CarDekho. The project analyzes vehicle information such as manufacturing year, selling price, present price, kilometres driven, fuel type, seller type, transmission, and ownership.

The main goal is to identify important patterns and factors that influence vehicle selling prices and resale value.

## Objectives

* Analyze vehicle manufacturing years and market trends
* Identify the highest and lowest selling prices
* Find the most frequently sold vehicles
* Analyze CNG and automatic transmission vehicles
* Study individual seller patterns
* Analyze vehicle depreciation
* Understand factors affecting selling price
* Compare cars and two-wheelers
* Identify unusual or exceptional vehicle prices

## Dataset

The dataset contains **301 vehicle records** with attributes including:

* Car Name
* Manufacturing Year
* Selling Price
* Present Price
* Kilometres Driven
* Fuel Type
* Seller Type
* Transmission
* Owner

## Technologies Used

* **Python** – Main programming language
* **Pandas** – Data cleaning, filtering, and analysis
* **NumPy** – Numerical calculations
* **Matplotlib** – Data visualization
* **Jupyter Notebook** – Development and analysis environment

## Analysis Performed

The project performs exploratory data analysis to understand:

* Vehicle selling patterns
* Price variations
* Vehicle depreciation
* Effect of vehicle age on price
* Effect of kilometres driven on price
* Most frequently sold vehicles
* Differences between cars and two-wheelers

## Key Insights

The analysis shows that newer vehicles generally have higher selling prices, while older vehicles tend to have lower prices because of depreciation.

Vehicles with lower kilometres driven generally have better selling prices. However, factors such as vehicle condition, brand, and model can also influence resale value.

1. Clone the repository.
2. Open the Jupyter Notebook.
3. Make sure the required Python libraries are installed.
4. Load the vehicle dataset.
5. Run the notebook cells to perform the analysis and generate visualizations.
